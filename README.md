# HSE_clubs_tg_bot
Телеграм бот и mini app с внеучебной деятельностью НИУ ВШЭ - Нижний Новгород

Telegram-бот и Telegram Mini App для поиска, просмотра и отслеживания внеучебных клубов, студенческих объединений и событий вуза.
Система должна позволять студенту:
находить клубы по названию, категории, тегам и интересам;
просматривать актуальную информацию о клубе;
переходить в Telegram-каналы, чаты и формы вступления;
подписываться на уведомления о конкретных клубах и категориях;
получать анонсы мероприятий из канала «активННик HSE»;
предлагать анонсы, новые клубы и правки в карточках;
управлять своими подписками.

Ссылка на бота: [@hse_nn_clubs_bot](https://t.me/hse_nn_clubs_bot)
Запуск бота:
'''bash
pip install -r requirements.txt
python bot/main.py'''
